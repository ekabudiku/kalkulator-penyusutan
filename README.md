✨ Fitur Utama
Multi-Sampel Properti: Mendukung penambahan beberapa sampel pembanding sekaligus (Rumah, Ruko, dan Lahan Kosong).
-Penyesuaian Otomatis (Adjustment):
-Penyesuaian jenis data (Penawaran vs Transaksi).
-Penyesuaian umur ekonomis bangunan berdasarkan tabel penyusutan, tahun pembuatan, dan renovasi.
-Penyesuaian waktu (tahun penilaian 2026) dan status kepemilikan (HM, HGB, TMA, HP).

Pilihan Skala Project ZNT & Threshold Dinamis:
-Skala 1:2.500 (Batas Maksimal RSD: 15%)
-Skala 1:10.000 (Batas Maksimal RSD: 25%)
-Skala 1:25.000 (Batas Maksimal RSD: 30%)

Indikator RSD & Peringatan Otomatis: Hasil analisis RSD akan memvalidasi data berdasarkan skala yang dipilih. Kartu hasil akan berubah menjadi warna merah (peringatan) apabila standar deviasi melampaui ambang batas toleransi.

Neumorphic & Dark Mode UI: Tampilan visual yang elegan, lembut, dan ramah mata dengan dukungan mode gelap (Dark Mode).

🛠️ Teknologi yang Digunakan
-HTML5 (Struktur markup semantik)
-CSS3 (Variabel kustom, Grid/Flexbox, Neumorphism design system)
-Vanilla JavaScript (ES6+) (Logika perhitungan matematis, manipulasi DOM, dan penyimpanan lokal tema)

🚀 Cara Menjalankan (Lokal)
Anda tidak memerlukan instalasi build tools (seperti Node.js atau NPM) karena aplikasi ini murni berjalan di sisi peramban (browser).

Clone repositori ini atau unduh dalam bentuk ZIP:
Bash
git clone https://github.com/ekabudiku/kalkulator-penyusutan.git
Buka folder proyek.

Klik dua kali pada file index.html (atau buka melalui browser favorit Anda seperti Chrome, Edge, atau Firefox).
